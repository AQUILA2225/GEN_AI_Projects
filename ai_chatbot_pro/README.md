# 🤖 AI Chatbot (Custom Assistant)

##  Overview
This project is a conversational AI chatbot built using Python and Streamlit. It allows users to interact with an AI assistant in real-time with different modes such as Tutor, Friend, and Coding Assistant.

##  Features
- Real-time chat interface
- Multiple assistant modes
- Conversation memory
- Reset chat functionality
- Typing effect and loading spinner
- Clean UI with sidebar

##  Tech Stack
- Python
- Streamlit
- Groq API
- OpenAI-compatible SDK
